# 🚨 CrisisGrid: AI-Powered Disaster Triage Dashboard

**🏆 C2C BUILD BEYOND IDEAS Hackathon 2026 Submission**

### 🌐 [CLICK HERE TO OPEN THE LIVE DASHBOARD](https://crisisgrid-jaipur.streamlit.app)

CrisisGrid is a real-time emergency response command center utilizing K-Means spatial clustering and machine learning (Ridge, Lasso, XGBoost) to optimize resource allocation, map hotspots, and manage medical triage in disaster zones.
